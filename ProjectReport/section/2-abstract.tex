\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{Abstract}

The \textbf{Spatial Emergency Dispatch System (SEDS)} is a completed web-based platform that automates emergency dispatch by eliminating manual jurisdiction lookup and enabling real-time responder coordination through spatial computation. Citizens report emergencies without login; the system uses PostGIS \texttt{ST\_Contains} queries to instantly assign the correct station based on zone containment (with nearest-distance fallback), and notifies responders via Server-Sent Events over Redis pub/sub with a 5-second polling safety net. Responders claim incidents atomically using Postgres row-level locking to prevent double-assignment, then progress through a lifecycle (\textit{Pending} → \textit{Responding} → \textit{Arrived} → \textit{Resolved}), with status updates pushed to citizens in real time. The system enforces role-based access control for Admin, Responder, and Citizen roles; admins manage stations, zones, and responders via an interactive map interface. The platform is built on Next.js 16 with MapLibre GL for WebGL rendering, a Node.js/Express REST API with Sequelize ORM, PostgreSQL 16 with PostGIS 3.4, and Redis for pub/sub, all containerized via Docker Compose. SEDS is production-ready for municipalities seeking an open-source, self-hostable alternative to proprietary CAD systems.
